# To-Do Organizer

تطبيق ذكي لتنظيم المهام باستخدام الذكاء الاصطناعي.

## نبذة عن المشروع

يساعد **To-Do Organizer** المستخدم على كتابة مهامه وأفكاره بطريقة طبيعية، حتى لو كانت غير مرتبة، ثم يقوم الذكاء الاصطناعي بتحليل النص وتنظيم المهام تلقائيًا.

يتم استخراج المعلومات الأساسية لكل مهمة وعرضها بطريقة واضحة ومنظمة.

## المميزات

* كتابة عدة مهام في نص واحد وبطريقة عفوية.
* تنظيم المهام تلقائيًا باستخدام الذكاء الاصطناعي.
* تحديد اسم كل مهمة.
* استخراج الموعد عند ذكره.
* تصنيف المهام تلقائيًا.
* تحديد مستوى الأولوية.
* إمكانية تحديد المهمة كمكتملة.
* عرض عدد المهام التي تم تنظيمها.
* واجهة عربية تدعم اتجاه الكتابة من اليمين إلى اليسار.
* تصميم مستوحى من أسلوب الدفاتر والمذكرات.

## آلية العمل

1. يكتب المستخدم مهامه في مربع النص.
2. يتم إرسال النص إلى الخادم.
3. يقوم Gemini بتحليل النص واستخراج المهام.
4. يتم تحديد اسم المهمة والموعد والتصنيف والأولوية.
5. يعرض التطبيق المهام بشكل منظم للمستخدم.

## تشغيل المشروع محليًا

### 1. تثبيت المتطلبات

تأكد من تثبيت Node.js على جهازك.

### 2. تثبيت الحزم

بعد فتح مجلد المشروع في Terminal، نفذ:

```bash
npm install
```

### 3. إعداد مفتاح Gemini API

أنشئ ملفًا باسم:

```text
.env
```

وأضف بداخله:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

استبدل `YOUR_API_KEY` بمفتاح Gemini API الخاص بك.

> لا تقم بمشاركة مفتاح API أو رفع ملف `.env` إلى GitHub.

### 4. تشغيل الخادم

نفذ:

```bash
node server.js
```

بعد تشغيل الخادم، افتح المتصفح على:

```text
http://localhost:3000
```

## الأمان

يتم استخدام ملف `.env` لحفظ مفتاح Gemini API بشكل منفصل عن ملفات المشروع.

تمت إضافة `.env` إلى `.gitignore` لمنع رفع المفتاح السري إلى GitHub.

## الهدف من المشروع

يهدف المشروع إلى تسهيل إدارة المهام اليومية من خلال الجمع بين بساطة كتابة المهام والقدرة على استخدام الذكاء الاصطناعي لتنظيمها تلقائيًا.
